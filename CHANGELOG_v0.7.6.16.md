# FMTS v0.7.6.16 — iPhone Mobile Header Hotfix

- Исправлена высота мобильной шапки на iPhone/PWA с `safe-area-inset-top`.
- Убрана причина, из-за которой header схлопывался до 58 px вместе с системной safe-area и элементы уезжали вверх.
- Мобильная шапка переведена на стабильную CSS Grid-сетку: меню, бренд, поиск и установка теперь вертикально выровнены.
- Синхронизирован верхний отступ контента с фактической высотой header.
- Обновлён PWA cache id.
