# FMTS v0.4.0 — Mobile / Technician UX

## Мобильный интерфейс
- Переработана адаптация под смартфоны 320–430 px и планшеты.
- Добавлена нижняя мобильная навигация: Главная, Заявки, Создать, ППР, Профиль.
- Увеличены touch-targets, поля ввода и кнопки; формы не вызывают нежелательное масштабирование на iPhone.
- Добавлены safe-area отступы для iPhone/PWA.
- Таблицы на основных экранах превращаются в карточки на телефоне вместо горизонтального скролла.
- Улучшены карточки оборудования, заявки, комментарии, фильтры, формы и модальные окна.

## Карточка мастера / техника
- Добавлен крупный блок объекта с адресом.
- Добавлена кнопка **«Маршрут до объекта»**.
- Выбор навигатора: Яндекс Карты, Google Maps, 2GIS.
- Навигатор строит маршрут от текущей позиции средствами самого приложения карт; FMTS не хранит геолокацию сотрудника.
- Добавлены быстрые действия: позвонить заявителю, скопировать адрес, открыть комментарии.
- На мобильном добавлена закреплённая панель быстрых действий над нижней навигацией.
- Если адрес объекта не заполнен, кнопка маршрута корректно отключается и сообщает причину.

## Совместимость
- Структура БД не изменена: маршрут использует существующее поле адреса объекта.
- Desktop-интерфейс сохранён.
- Версия service worker обновлена, чтобы мобильные устройства получили свежий CSS после деплоя.
