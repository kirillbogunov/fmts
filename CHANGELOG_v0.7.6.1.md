# FMTS v0.7.6.1 — Checklist Builder UX Hotfix

- Полностью упрощён конструктор чек-листов ТО/ППР.
- Убраны из основного сценария выбор родителя, ручной sort_order и сложная форма из шести полей.
- Новый пункт верхнего уровня создаётся одной строкой `Добавить пункт`.
- У каждого пункта есть понятная кнопка `+ подпункт`; FMTS сам создаёт 1.1 / 1.1.1 и т.д.
- Нумерация остаётся полностью автоматической.
- Редактирование названия, подсказки и обязательности открывается только по кнопке карандаша.
- Добавлены простые кнопки вверх/вниз для изменения порядка среди соседних пунктов.
- Добавлена короткая визуальная подсказка из трёх шагов.
- На мобильном кнопки увеличены, формы раскрываются прямо под выбранным пунктом и не требуют сложных select-полей.
- После добавления/редактирования нужный план автоматически раскрывается и прокручивается в область видимости.
- Состояние раскрытого конструктора запоминается в браузере.
