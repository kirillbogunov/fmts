# FMTS v0.7.6.6 — SLA Calendar UX Refresh

- Полностью переработан интерфейс SLA-календарей.
- Рабочие дни выбираются кнопками Пн–Вс вместо ввода `0,1,2,3,4`.
- Добавлены быстрые шаблоны 5/2, 6/1 и «Каждый день».
- Часовой пояс выбирается из понятного списка с человекочитаемыми подписями.
- Для Казахстана отображается понятная подпись UTC+5.
- Праздники и дополнительные выходные добавляются по одной дате и отображаются чипами с удалением.
- Создание календаря разбито на 3 простых шага.
- Существующие календари отображаются компактно, редактирование раскрывается только по кнопке «Настроить».
- Добавлен живой итог графика и расчёт продолжительности смены.
- Раздел SLA сервисов переведён в карточный формат.
- Мобильный интерфейс адаптирован под управление пальцем.
