# Обновление FMTS до v0.7.6.17

1. Обновите файлы проекта.
2. На Render выполните **Manual Deploy → Clear build cache & deploy**.
3. Новая таблица исключений графика создаётся автоматически через SQLAlchemy `create_all`; ручной SQL не требуется.
4. Существующие записи `technician_availability` сохраняются и продолжают использоваться.
5. После деплоя откройте **Управление → Графики сотрудников** и при необходимости сохраните недельный график каждому технику.
