# FMTS v0.7.1 — Lifecycle / SLA Pause / Reminders

## Что добавлено

- Полная история переходов статусов заявки с пользователем, датой и источником изменения.
- Расчёт фактического времени нахождения заявки в каждом статусе.
- Статус `Ожидание материалов` автоматически ставит SLA на паузу; после возобновления срок SLA продлевается на точное время ожидания.
- SLA-эскалации не срабатывают, пока заявка находится в ожидании.
- Личные напоминания по заявке; после наступления срока создаётся уведомление FMTS и используются подключённые внешние каналы уведомлений.
- Оптимистическая блокировка редактирования: устаревшая открытая карточка не может затереть изменения другого диспетчера/руководителя.
- Таймер техника, массовые операции и синхронизация 1С используют общий механизм истории статусов.
- Для старых заявок создаётся безопасная стартовая запись истории без выдумывания неизвестных старых переходов.

## База данных

Миграция выполняется автоматически. Добавляются поля `sla_paused_at`, `sla_paused_seconds`, `edit_version`, а также таблицы `ticket_status_history` и `ticket_reminders`. Ручной SQL не требуется.
