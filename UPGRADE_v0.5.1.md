# Обновление FMTS до v0.5.1

1. Сделайте резервную копию базы и каталога `uploads`.
2. Замените файлы проекта версией v0.5.1.
3. На Render выполните `Manual Deploy → Deploy latest commit`.
4. Supabase вручную изменять не требуется: новая таблица учёта времени создастся автоматически при запуске.
5. После деплоя откройте любую заявку. В карточке появится блок **«Учёт времени работ»**.

Существующие заявки сохраняются. Для старых заявок фактическое время будет равно нулю до тех пор, пока не появятся записи таймера или ручные записи.
