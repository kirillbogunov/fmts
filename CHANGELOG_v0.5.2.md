# FMTS v0.5.2 — RBAC / Access Control

- Центральная матрица прав в `app/access.py`.
- Row-level security для заявок: заявитель видит свои, техник — назначенные, диспетчер/руководитель/администратор — все.
- Серверная проверка прав для Web и REST API.
- Жёсткая схема переходов статусов по ролям.
- Только активный техник может быть внутренним исполнителем заявки/ППР.
- Таймер и ручной ввод времени доступны только назначенному технику; удаление времени — только администратору.
- Завершение/закрытие требует исполнителя, комментария мастера и зафиксированного времени.
- Защищённые вложения вместо публичной раздачи `/uploads`.
- Swagger/OpenAPI только для администратора.
- Новый `audit_logs` и страница `Журнал контроля` для руководителя/администратора.
- Управление ролью и активностью сотрудников; защита от отключения последнего администратора.
- UI автоматически скрывает недоступные разделы и действия.
