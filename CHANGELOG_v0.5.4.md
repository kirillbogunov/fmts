# FMTS v0.5.4 — материалы в заявке и фактическая стоимость

- В карточке заявки появился отдельный реестр списанных материалов.
- Для каждой строки отображаются материал, количество, единица, дата и сотрудник, выполнивший списание.
- Для ролей с правом просмотра затрат дополнительно отображаются цена на момент списания и сумма строки.
- Цена фиксируется в момент списания и больше не меняется задним числом при изменении цены складской позиции.
- Стоимость материалов автоматически суммируется в `parts_cost` заявки.
- В карточке заявки добавлен финансовый блок: работы/услуги + материалы = итоговая стоимость заявки.
- Для старых движений выполняется безопасная автоматическая миграция с заполнением исторической цены текущей ценой справочника на момент обновления.
- В аудит списания добавлены цена и сумма.
- Мобильное отображение таблицы материалов адаптировано под карточный режим.
