# FMTS v0.7.3 — CMDB / Categories / Labor Analytics

- Массовый импорт оборудования / CMDB из `.xlsx` и `.csv`.
- Импорт склада / ЗИП из `.xlsx` и `.csv`.
- Готовые Excel-шаблоны импорта из интерфейса.
- Иерархические категории для заявок, оборудования, базы знаний и сервисов.
- Категории заявок и оборудования используют полный путь дерева.
- Улучшенный глобальный поиск с поддержкой русских словоформ и ранжированием.
- Расчётная ставка сотрудника в ₸/час.
- Снимок ставки и стоимость на каждом завершённом сеансе работы.
- Автоматический расчёт стоимости трудозатрат заявки.
- Сохранена отдельная ручная стоимость дополнительных работ/услуг.
- Новый отчёт `Аналитика → Трудозатраты`, детализация по заявкам, объектам и сотрудникам.
- CSV-выгрузка трудозатрат.
- Безопасный backfill старых сеансов: пересчитываются только записи без сохранённой стоимости.
- Тематическое меню расширено пунктами `Импорт данных`, `Классификаторы`, `Трудозатраты`.
- Additive migration с сохранением старых данных.
- PWA cache обновлён до v0.7.3.
