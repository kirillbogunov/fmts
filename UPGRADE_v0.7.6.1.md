# Обновление FMTS до v0.7.6.1

Это UX-hotfix поверх v0.7.6. Изменений схемы базы данных нет.

1. Замените файлы проекта версией v0.7.6.1.
2. Render → Manual Deploy → Clear build cache & deploy.
3. На телефоне полностью закройте PWA и откройте снова.

Все созданные ранее планы, пункты и иерархия чек-листов сохраняются без изменений.
