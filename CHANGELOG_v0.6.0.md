# FMTS v0.6.0 — Enterprise ServiceDesk Pack

Версия расширяет FMTS от ТОиР/хозяйственной службы до полноценного ServiceDesk-контура, сохраняя оборудование, ППР, склад, KPI, мобильную работу мастеров и жёсткий RBAC.

## Добавлено

- каталог сервисов с собственным SLA, категорией и приоритетом;
- пользовательские поля заявок по сервисам: текст, число, дата, список, Да/Нет;
- автоматические правила маршрутизации: условия по категории/приоритету/объекту/заголовку, автоназначение, SLA, уведомление руководителя;
- автоназначение на наименее загруженного доступного техника;
- график доступности техников;
- SLA warning + overdue escalation с уведомлениями;
- центр уведомлений внутри FMTS;
- Web Push для PWA при заданных VAPID-ключах;
- уведомления по SMTP, Telegram и WhatsApp webhook;
- приём заявок из IMAP-почты; письмо с номером SR-YYMMDD-NNN в теме добавляет комментарий в существующую заявку;
- база знаний с поиском, тегами, привязкой к сервису и категории оборудования;
- рекомендации статей прямо в карточке заявки;
- глобальный поиск по заявкам, оборудованию и базе знаний;
- расширенные фильтры заявок и сохранённые представления;
- связанные / дочерние / дублирующие заявки;
- согласования внутри заявки;
- оценка работы заявителем; средняя оценка показывается в месячном KPI;
- конструктор управленческих отчётов по объекту, категории, статусу, исполнителю и типу оборудования;
- подписки на отчёты через e-mail при настроенном SMTP;
- расширенная CMDB: родительский узел, дочерние активы, владелец и критичность оборудования;
- TOTP 2FA для пользователей;
- опциональная LDAP / Active Directory авторизация с локальным fallback;
- контакты пользователя для e-mail / Telegram / WhatsApp уведомлений;
- новые API endpoints для Web Push;
- service worker умеет принимать push и открывать нужную страницу FMTS.

## Обновление

Миграции остаются additive. При запуске FMTS сам добавит новые nullable/default-поля к `users`, `equipment`, `tickets` и создаст новые таблицы. Ручной SQL в Supabase не требуется.
