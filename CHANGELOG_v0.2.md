# v0.2

- Привязка к существующему `Документ.ЗаявкаХозОтдела`.
- Использование существующего `Справочник.Подразделения`.
- Двусторонняя синхронизация заявок 1С ↔ Web.
- Карта старых перечислений статусов, приоритетов и категорий.
- Webhook `POST /api/1c/webhook/tickets` с `X-TOIR-TOKEN`.
- Технический `WebID` для защиты от дублей при цикле Web → 1С → Web.
- Сохранение GUID документа 1С в карточке.
- Совместимость с БД v0.1 через лёгкую SQLite-миграцию.
- Поля `Заявитель`, `Телефон`, `Кабинет/зона`, `Мастер`, `КомментарийМастера`.
- Автосинхронизация новых/изменённых заявок и ППР в 1С при включённой интеграции.
- PWA manifest + service worker + мобильная навигация + иконки.
- Смена пароля из профиля.
- Готовые инструкции Cloudflare Tunnel / доступ с телефона.
- Готовые BSL-модули и пошаговая инструкция конфигуратора 1С.

## Русская локализация интерфейса
- Все статусы заявок отображаются по-русски: Новая, Назначена, В работе, Ожидание материалов, Выполнена, Закрыта, Отменена.
- Все приоритеты отображаются по-русски: Низкий, Обычный, Высокий, Срочный.
- Роли пользователей отображаются по-русски: Заявитель, Техник, Диспетчер, Руководитель, Администратор.
- Статусы оборудования отображаются по-русски: Работает, Неисправно, В ремонте, Списано.
- Технические коды в БД/API сохранены для совместимости; API дополнительно возвращает русские поля `status_name` / `priority_name`.
