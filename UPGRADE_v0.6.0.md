# Обновление FMTS до v0.6.0

1. Сделайте резервную копию базы и каталога `uploads`.
2. Замените код проекта файлами v0.6.0.
3. Не удаляйте существующий `DATABASE_URL` и секреты Render.
4. Выполните обычный redeploy. `bootstrap.py` теперь сам запускает additive migrations перед обращением к существующим пользователям.
5. После запуска проверьте `/api/health` — версия должна быть `0.6.0`.

Новые интеграции выключены по умолчанию. Для базовой работы ничего дополнительно настраивать не нужно.

Для e-mail канала заполните `IMAP_*` и `IMAP_DEFAULT_SITE_ID`; для исходящих уведомлений — `SMTP_*`; для Telegram — `TELEGRAM_BOT_TOKEN`; для WhatsApp — webhook вашего API-провайдера; для Web Push — VAPID-ключи; для LDAP/AD — `LDAP_*`.

Рекомендуется для руководителей и администраторов включить 2FA через `Профиль → Двухфакторная авторизация`.
