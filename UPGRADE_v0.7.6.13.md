# Обновление FMTS до v0.7.6.13

1. Сделайте обычный deploy новой версии. Миграции выполняются автоматически.
2. Один раз выполните локально `python scripts/generate_vapid_keys.py`.
3. Скопируйте три строки `PUSH_VAPID_*` в Render → Environment.
4. `PUSH_VAPID_SUBJECT` желательно заменить на рабочий e-mail администратора.
5. Выполните `Clear build cache & deploy`.
6. На телефоне откройте `Профиль → Push на телефон` и нажмите `Включить push`.
7. На iPhone откройте FMTS через Safari, добавьте его на экран «Домой», затем включайте push уже из установленного PWA.

Секретный `PUSH_VAPID_PRIVATE_KEY` нельзя хранить в публичном репозитории.
