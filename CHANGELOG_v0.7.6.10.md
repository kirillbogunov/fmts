# FMTS v0.7.6.10 — Category Tree UX

- Полностью упрощён раздел «Иерархические категории».
- Убраны технические поля порядка и числовые значения из пользовательского интерфейса.
- Добавлено наглядное дерево с раскрытием/сворачиванием веток.
- Добавлены быстрые действия «+ Подкатегория», «Изменить» и меню дополнительных действий.
- Создание и редактирование категории теперь требует только название и родительскую категорию.
- Порядок новых категорий FMTS назначает автоматически внутри выбранной ветки.
- Добавлен живой поиск по дереву категорий.
- Состояние свёрнутых веток запоминается браузером.
- Улучшена desktop/mobile-верстка.
- Существующие данные и sort_order сохранены для обратной совместимости.
