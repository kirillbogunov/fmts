# FMTS v0.2.2

- Исправлена подсветка после русификации: CSS больше не строится из русского текста статуса.
- Источник цветов перенесён в 1С.
- Добавлен кэш `ui_styles` для последней успешной конфигурации из 1С.
- Подсветки из 1С применяются к статусам, приоритетам, категориям и статусам оборудования.
- Названия значений в интерфейсе могут приходить из 1С.
- SLA по приоритетам может задаваться в 1С (`SLAЧасов`).
- Автоматическая синхронизация настроек оформления по умолчанию каждые 300 секунд.
- Добавлена ручная синхронизация `Интеграция → Подсветки / SLA`.
- Добавлен webhook `/api/1c/webhook/ui` для возможной мгновенной отправки настроек из 1С.
- API заявок и оборудования теперь возвращает стили, полученные из 1С.
- Добавлены инструкции и BSL-код для регистра `НастройкиПодсветкиТОИР`.
