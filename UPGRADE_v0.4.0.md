# Обновление FMTS до v0.4.0

1. Распакуйте архив. Внутри сразу находятся `app/`, `requirements.txt`, `README.md` и остальные файлы проекта — дополнительной корневой папки нет.
2. Загрузите содержимое в корень GitHub-репозитория `fmts` с заменой существующих файлов.
3. В Render оставьте **Root Directory пустым**.
4. Build Command: `pip install -r requirements.txt`
5. Start Command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
6. Выполните **Manual Deploy → Deploy latest commit**.
7. После деплоя на телефоне обновите страницу. Service Worker v0.4.0 автоматически удалит старый статический кэш.

## Для маршрута мастера
Откройте **Объекты** и убедитесь, что у нужного магазина/площадки заполнено поле **Адрес**. В карточке заявки появится кнопка **«Маршрут до объекта»**. FMTS не запрашивает и не хранит координаты сотрудника: стартовую позицию определяет выбранный навигатор.

Изменений структуры базы данных в v0.4.0 нет.
