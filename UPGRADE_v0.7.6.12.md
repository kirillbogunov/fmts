# Обновление FMTS до v0.7.6.12

1. Замените файлы проекта содержимым архива.
2. Render: `Manual Deploy → Clear build cache & deploy`.
3. На телефоне полностью закройте PWA/браузер и откройте снова. При необходимости удалите приложение с домашнего экрана и установите повторно.

Изменений схемы БД нет. Ручной SQL не требуется.
