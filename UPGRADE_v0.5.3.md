# Обновление FMTS до v0.5.3

1. Замените файлы проекта содержимым архива v0.5.3.
2. На Render выполните **Manual Deploy → Deploy latest commit**.
3. Базу Supabase вручную менять не нужно: при старте FMTS добавит поле `comment_id` в таблицу `attachments`, если его ещё нет.
4. Для QR на Render по-прежнему должна быть переменная:

```env
PUBLIC_BASE_URL=https://fmts-demo.onrender.com
COOKIE_HTTPS_ONLY=true
```

Опционально:

```env
COMMENT_PHOTO_MAX_COUNT=5
COMMENT_PHOTO_MAX_MB=12
```

Если установленная на iPhone иконка продолжает показывать старую шапку, полностью закройте PWA и откройте снова. Если iOS продолжает держать старую конфигурацию status-bar, удалите и заново добавьте FMTS на экран «Домой» — это ограничение кэша standalone web app iOS.

> Важно для Render Free: локальная папка `uploads` не является надёжным постоянным хранилищем между пересборками/перезапусками. Для рабочего хранения фото следующим этапом рекомендуется подключить Supabase Storage или другое объектное хранилище.
