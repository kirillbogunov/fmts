# FMTS v0.6.3 — Mobile navigation redesign

- Rebuilt the mobile side drawer for iPhone/Android.
- Drawer now always fills the full dynamic viewport (`100dvh`) and never leaves a white lower area.
- Navigation is independently scrollable; user/profile block remains stable at the bottom.
- Added explicit close control, dark backdrop, scroll lock and Escape handling.
- Improved menu icons, active state, notification counter and API row.
- Desktop sidebar remains compatible with the same role-based navigation.
- Service-worker cache bumped so installed PWA receives the new CSS immediately.
