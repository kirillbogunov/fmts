# Обновление до FMTS v0.5.4

1. Загрузите содержимое архива в репозиторий поверх текущей версии.
2. Выполните обычный Deploy latest commit в Render.
3. SQL вручную выполнять не требуется.

При старте FMTS автоматически добавит в `stock_movements` поля:

- `unit_cost_snapshot` — цена материала на момент списания;
- `amount` — сумма списания;
- `issued_by_id` — кто выполнил списание.

Существующие записи будут мягко дополнены текущей ценой складской позиции, если историческая цена ранее не сохранялась.
