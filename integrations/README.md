# Интеграции

Ядро ТОиР работает самостоятельно. Все интеграции являются дополнительными коннекторами.

- `1c/` — совместимость с ранее подготовленным HTTP-сервисом 1С.
- REST API системы доступен в `/docs`.
- В будущих версиях сюда могут быть добавлены Telegram, email, ERP/WMS и другие коннекторы.

По умолчанию `ONEC_ENABLED=false` и `ONEC_AUTO_PUSH=false`.
