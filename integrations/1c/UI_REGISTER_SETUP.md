# Подсветки и SLA из 1С

В версии 0.2.2 **1С является источником оформления** статусов, приоритетов, категорий и статусов оборудования.
Веб-приложение только кэширует последнюю успешно полученную настройку.

## 1. Добавить регистр сведений

Имя: `НастройкиПодсветкиТОИР`

Тип: независимый, непериодический.

### Измерения

| Имя | Тип | Длина |
|---|---|---:|
| `Тип` | Строка | 30 |
| `Код` | Строка | 100 |

### Ресурсы

| Имя | Тип | Примечание |
|---|---|---|
| `Наименование` | Строка 160 | Что видит пользователь |
| `ЦветФона` | Строка 20 | HTML цвет, например `#FDE2E5` |
| `ЦветТекста` | Строка 20 | Например `#B12B36` |
| `ЦветГраницы` | Строка 20 | Например `#F3C4C9` |
| `SLAЧасов` | Число 10,0 | Используется для приоритетов; для остальных 0 |
| `Порядок` | Число 5,0 | Порядок в списках |
| `Активен` | Булево | Да/Нет |

## 2. Какие коды использовать

### Тип `status`

| Код | Наименование |
|---|---|
| `new` | Новая |
| `assigned` | Назначена |
| `in_progress` | В работе |
| `waiting` | Ожидание материалов |
| `resolved` | Выполнена |
| `closed` | Закрыта |
| `cancelled` | Отменена |

### Тип `priority`

| Код | Наименование | Рекомендуемый SLA |
|---|---|---:|
| `low` | Низкий | 72 |
| `normal` | Обычный | 24 |
| `high` | Высокий | 8 |
| `critical` | Срочный | 2 |

### Тип `category`

Код должен совпадать со значением категории в `ЗаявкаХозОтдела`:
`Электрика`, `Сантехника`, `Мебель`, `Отделка`, `Кондиционер`, `Окна`, `Двери`, `Компьютер`, `Другое`.

### Тип `equipment_status`

| Код | Наименование |
|---|---|
| `working` | Работает |
| `broken` | Неисправно |
| `repair` | В ремонте |
| `decommissioned` | Списано |

## 3. Добавить HTTP-метод

В существующем HTTP-сервисе `TOIR`:

- URL-шаблон: `/ui`
- метод: `GET`
- обработчик: `GET_UI`

Код обработчика находится в `HTTPService_TOIR_UI_Addon.bsl`.

Итоговый адрес при публикации `/hs/toir/v1`:

`/hs/toir/v1/ui`

## 4. Синхронизация

В `.env` приложения:

```env
ONEC_UI_PATH=/hs/toir/v1/ui
```

Приложение автоматически перечитывает оформление из 1С каждые 5 минут.
Можно поставить `60`, чтобы обновление происходило примерно раз в минуту.

Также доступна ручная кнопка:

**Интеграция → Подсветки / SLA → Синхронизировать**.

## 5. Что происходит при недоступности 1С

Последняя успешно полученная конфигурация хранится в таблице `ui_styles` веб-приложения.
Поэтому при временном отключении 1С цвета не сбрасываются.

Если синхронизация ещё ни разу не выполнялась, используются безопасные резервные цвета.
После первой успешной синхронизации отображение берётся из 1С.


> В v0.3 ядро ТОиР самостоятельно. Импорт оформления из 1С выполняется только вручную или webhook и не является обязательным.
