# Подключение FMTS к уже существующей 1С

1. Сделайте резервную копию базы/конфигурации.
2. В `Документ.ЗаявкаХозОтдела` добавьте реквизит `WebID`, тип Строка 36. На форму выводить не обязательно.
3. В конфигураторе создайте общий модуль `TOIRWebAPI`, вставьте `TOIRWebAPI_CommonModule.bsl`.
4. В модуле `TOIRWebAPI` задайте IP/имя ПК, где запущено приложение, порт 8000 и токен.
5. В модуле объекта `Документ.ЗаявкаХозОтдела` замените старую отправку в Google Sheets на `TOIRWebAPI.ОтправитьЗаявку(Ссылка)`.
6. Создайте HTTP-сервис `TOIR`, корневой URL `toir`, шаблон `v1`, затем ресурсы `sites` и `tickets`. Назначьте обработчики из `HTTPService_TOIR_Core_Module.bsl`.
7. Опубликуйте изменения через уже работающий Apache/HTTPS.
8. В `.env` приложения укажите адрес опубликованной базы в `ONEC_BASE_URL`, пользователя 1С и пароль; включите `ONEC_ENABLED=true`.
9. Значение `ONEC_WEBHOOK_TOKEN` в `.env` должно в точности совпадать с `ТокенTOIR()` в 1С.
10. Перезапустите приложение и откройте «Интеграция 1С» → синхронизация подразделений и заявок.

## Проверка

- Создайте тестовую `ЗаявкаХозОтдела` в 1С — она должна появиться в веб-приложении.
- Создайте заявку в веб-приложении — должен появиться документ `ЗаявкаХозОтдела`, а в карточке веб-приложения отобразится GUID 1С.
- Измените статус с любой стороны — после сохранения значение должно обновиться на второй стороне.

Если 1С и приложение расположены на разных ПК, в `ХостTOIR()` укажите LAN IP сервера приложения. Публичный домен Cloudflare для внутреннего обмена 1С → приложение не нужен.

## Шаг: включить подсветки из 1С (v0.2.2)

1. Создайте регистр сведений `НастройкиПодсветкиТОИР` по `UI_REGISTER_SETUP.md`.
2. В HTTP-сервисе `TOIR` создайте шаблон `/ui`, метод GET, обработчик `GET_UI`.
3. Код `GET_UI` возьмите из `HTTPService_TOIR_UI_Addon.bsl` и вставьте в модуль сервиса.
4. Один раз выполните `UI_DEFAULT_VALUES.bsl`, чтобы заполнить стартовые значения.
5. В `.env` веб-приложения должны быть:
   `ONEC_UI_PATH=/hs/toir/v1/ui`.
6. Откройте в ТОиР `Интеграция` и нажмите `Подсветки / SLA → Синхронизировать`.
7. Измените любой цвет в регистре 1С и повторите синхронизацию: цвет должен измениться в браузере и PWA.

После первой синхронизации 1С становится основным источником названий/цветов для
статусов, приоритетов, категорий и статусов оборудования. Последняя версия
настроек кэшируется локально и продолжает использоваться, если 1С временно
недоступна.


> В v0.3 ядро ТОиР самостоятельно. Импорт оформления из 1С выполняется только вручную или webhook и не является обязательным.
