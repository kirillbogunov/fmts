# Обновление FMTS до v0.7.1

1. Сделайте резервную копию базы Supabase/PostgreSQL.
2. Замените файлы проекта содержимым архива.
3. В Render выполните `Manual Deploy -> Clear build cache & deploy`.
4. При первом старте FMTS автоматически добавит поля жизненного цикла и создаст таблицы истории/напоминаний.
5. Откройте существующую заявку: появятся блоки `История статусов` и `Мои напоминания`.

Для старых заявок FMTS не реконструирует несуществующие исторические данные задним числом. Полный учёт переходов начинается с v0.7.1.
