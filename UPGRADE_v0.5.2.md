# Обновление FMTS до v0.5.2

1. Замените файлы проекта содержимым архива v0.5.2.
2. В Render выполните **Manual Deploy → Deploy latest commit**.
3. Таблицу `audit_logs` приложение создаст автоматически через SQLAlchemy `create_all` — вручную в Supabase ничего создавать не нужно.
4. После входа администратором откройте **Пользователи** и проверьте роли сотрудников.
5. Руководителю/администратору доступен новый раздел **Журнал контроля**.

Рекомендуется перед переводом в рабочую эксплуатацию проверить каждую роль отдельной тестовой учётной записью.
