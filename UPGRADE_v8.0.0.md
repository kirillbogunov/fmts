# Обновление FMTS до v8.0.0

1. Сделайте резервную копию базы данных.
2. Замените проект версией v8.0.0.
3. На Render выполните `Manual Deploy → Clear build cache & deploy`.
4. Миграций схемы БД для Report Studio не требуется.
5. После деплоя перезапустите PWA/браузер, чтобы обновился service worker.
