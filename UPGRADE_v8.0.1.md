# Обновление FMTS до v8.0.1

1. Замените файлы проекта версией v8.0.1.
2. На Render выполните `Manual Deploy → Clear build cache & deploy`.
3. На iPhone полностью закройте установленный FMTS/PWA и откройте снова.
4. Изменений схемы базы данных нет, ручной SQL не требуется.

Основные изменения касаются единой мобильной сетки, нижней навигации, safe-area и карточки заявки.
