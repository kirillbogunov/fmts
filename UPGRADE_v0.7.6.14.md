# Обновление до FMTS v0.7.6.14

1. Замените файлы проекта новой версией.
2. На Render выполните **Manual Deploy → Clear build cache & deploy**.
3. SQL и миграции БД не требуются.
4. Существующие VAPID-ключи Web Push менять не нужно.
5. На iPhone/Android после деплоя полностью закройте установленное PWA и откройте снова, чтобы обновился Service Worker и SVG-спрайт.
