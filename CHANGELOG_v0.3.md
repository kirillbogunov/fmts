# v0.3.0 — Standalone Core

- ТОиР полностью работает без 1С.
- Локальная база стала главным источником статусов, приоритетов, SLA, категорий и подсветок.
- Добавлен экран `Настройки` для управления справочными значениями.
- Убрана фоновая синхронизация цветов/SLA из 1С.
- 1С переведена в опциональный коннектор (`ONEC_ENABLED=false` по умолчанию).
- Автоматическая отправка заявок в 1С выключена по умолчанию (`ONEC_AUTO_PUSH=false`).
- Webhook 1С закрыты, когда коннектор отключён.
- Старый пакет 1С перенесён в `integrations/1c/`.
- Добавлен чистый bootstrap без демонстрационных объектов.
- Добавлен отдельный `run_demo_windows.bat` для презентации.
- Docker-развёртывание переведено на PostgreSQL 16.
- SQLite оставлен для быстрого локального запуска.
- Версия API обновлена до 0.3.0.
