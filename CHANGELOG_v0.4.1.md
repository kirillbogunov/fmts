# FMTS v0.4.1 — QR Public URL Fix

- Исправлена генерация QR-кодов оборудования: `127.0.0.1:8000` больше не зашивается в ссылку.
- Добавлена настройка `PUBLIC_BASE_URL` для публичного адреса FMTS.
- На Render поддерживается автоматический fallback через `RENDER_EXTERNAL_URL`.
- Если публичный адрес явно не задан, FMTS определяет схему и хост из текущего HTTP-запроса/proxy-заголовков.
- Сохранена обратная совместимость с прежней переменной `BASE_URL`.
- Версия приложения повышена до `0.4.1`.
- Обновлён cache key service worker, чтобы мобильные клиенты получили актуальные статические файлы.
