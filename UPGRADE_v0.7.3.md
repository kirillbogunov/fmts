# Обновление FMTS до v0.7.3

1. Перед обновлением сделайте резервную копию PostgreSQL / Supabase.
2. Замените файлы проекта версией v0.7.3.
3. Убедитесь, что зависимости установлены из `requirements.txt` (в v0.7.3 добавлен `openpyxl==3.1.5`).
4. В Render выполните `Manual Deploy → Clear build cache & deploy`.
5. Миграция выполняется автоматически, ручной SQL не требуется.
6. Администратор задаёт расчётные ставки сотрудников в разделе `Пользователи`.
7. Старые рабочие сеансы специально не получают стоимость автоматически. После заполнения ставок можно открыть `Аналитика → Трудозатраты` и нажать пересчёт только для записей без сохранённой стоимости.
8. После обновления перезапустите установленное PWA-приложение, чтобы обновился кэш.

## Изменения схемы

Добавляются поля:
- `users.hourly_rate`;
- `tickets.manual_labor_cost`;
- `ticket_work_sessions.hourly_rate_snapshot`;
- `ticket_work_sessions.labor_amount`.

Добавляется таблица `category_nodes` для иерархических классификаторов.

Существующее значение `tickets.labor_cost` сохраняется и переносится в ручную составляющую стоимости работ. После v0.7.3 итоговая стоимость труда заявки складывается из ручной суммы дополнительных работ/услуг и фактических завершённых сеансов работы.
