# FMTS v0.5.5 — Карточка складской позиции

- В разделе «Склад / ЗИП» код и наименование позиции открывают отдельную карточку.
- Добавлена сводка: текущий остаток, минимальный остаток, сколько списано, количество заявок и финансовые показатели для ролей с доступом к стоимости.
- Добавлен блок «Куда списывалось» с группировкой по заявкам, объектам и оборудованию.
- Добавлена полная история списаний: дата, количество, зафиксированная цена/сумма, сотрудник, заявка, объект и оборудование.
- Сохранена строгая ролевая безопасность: техник видит историю только по доступным ему заявкам; финансовые суммы — только роли с правом `ticket.cost`.
