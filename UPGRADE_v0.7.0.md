# Обновление FMTS до v0.7.0

1. Перед обновлением сделайте резервную копию базы PostgreSQL/Supabase и папки вложений.
2. Замените файлы проекта содержимым архива v0.7.0.
3. На Render выполните `Manual Deploy → Clear build cache & deploy`.
4. Ручной SQL не требуется: при старте FMTS выполнит только добавочные миграции.
5. После запуска проверьте: Дашборд, Заявки, Группы исполнителей, Шаблоны / наряды.
6. На установленном PWA полностью закройте приложение и откройте заново, чтобы обновился service worker.

Новых обязательных переменных окружения в этой фазе нет.
