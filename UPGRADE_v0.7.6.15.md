# Обновление до FMTS v0.7.6.15

1. Замените файлы проекта версией v0.7.6.15.
2. На Render выполните `Manual Deploy → Clear build cache & deploy`.
3. Миграции БД не требуются: обновление касается мобильной разметки, CSS и PWA-кэша.
4. После деплоя полностью закройте установленное PWA на телефоне и откройте снова.
