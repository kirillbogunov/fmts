# FMTS v0.5.1 — Actual Work Time Tracking

## Добавлено

- Учёт фактического времени работы по каждой заявке.
- Кнопки **«Начать работу» / «Остановить таймер»** в карточке заявки.
- На мобильном таймер доступен прямо из нижней панели быстрых действий.
- Одновременно у одного сотрудника может идти только один таймер: запуск по новой заявке автоматически закрывает предыдущий сеанс.
- При закрытии, выполнении или отмене заявки активные таймеры по ней автоматически останавливаются.
- При смене исполнителя активный таймер старого исполнителя закрывается.
- История сеансов: сотрудник, начало, окончание, длительность и комментарий.
- Ручное добавление времени, если работу забыли запустить таймером.
- Возможность удалить ошибочную запись времени.
- В списке заявок добавлена колонка **«Время работ»**.
- В карточке заявки показывается общий факт времени и разбивка по сотрудникам.
- В месячный отчёт **KPI / Рейтинг** добавлено фактически учтённое время по каждому ремонтнику и по команде.
- Фактическое время пока не влияет на формулу KPI, чтобы не стимулировать искусственное завышение или занижение длительности работ.

## База данных

Добавляется новая таблица `ticket_work_sessions`. На PostgreSQL/Supabase она создаётся автоматически через `Base.metadata.create_all()`. Ручные SQL-миграции не требуются.
