# FMTS v0.7.6.13 — Mobile Web Push

- Полноценное подключение Web Push для PWA на телефоне.
- Подключение/отключение текущего устройства и тестовый push.
- Список подключённых устройств в профиле.
- Настройки событий: назначения, комментарии, статусы, SLA, ТО/ППР, напоминания, ЗИП и прочие события.
- Тихие часы с учётом часового пояса пользователя.
- Push при назначении заявки, новом комментарии, изменении статуса заявителя, SLA, ППР, напоминаниях и низком остатке ЗИП.
- Автоматическое отключение устаревших push-подписок при ответе 404/410 от push-сервиса.
- Мобильная подсказка «Включить уведомления» без автоматического запроса разрешения.
- Улучшенный Service Worker для перехода прямо в связанную заявку.
- Скрипт `scripts/generate_vapid_keys.py` для генерации VAPID-ключей Render.
