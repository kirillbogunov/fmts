# FMTS v8.0.0 — Analytics / Report Studio

- Полностью переработан «Конструктор отчётов».
- Добавлена KPI-сводка: всего, открыто, выполнено, просрочено, SLA, часы, среднее время решения и затраты.
- Интерактивная динамика созданных и выполненных заявок.
- Круговая структура статусов.
- Сравнение групп по заявкам, выполнению и просрочкам.
- Финансовая диаграмма работ и материалов для ролей с доступом к стоимости.
- Расширенная таблица с процентом выполнения, SLA, временем решения, трудозатратами и затратами.
- Быстрый выбор периода 7 / 30 / 90 / 365 дней.
- CSV-выгрузка текущего аналитического среза.
- Подписка сохраняет текущую группировку и период.
- Полная адаптация Report Studio под телефон.
- Обновлён PWA cache-id.
